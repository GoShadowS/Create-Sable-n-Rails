# Create: Sable 'n' Rails

**Неофициальный экспериментальный проект совместимости** контрапций Create и sub-levels Sable. Это не официальный порт и проект не одобрен командами Create, Create: Interactive или Sable. Valkyrien Skies ship objects не используются.

## Целевая платформа

- Minecraft **1.21.1**, Java **21**, только **NeoForge**.
- Зафиксированные в сборке версии: NeoForge `21.1.228`, Create `6.0.10-280`, Sable `2.0.6`, Ponder `1.0.82`, Flywheel `1.0.6`, Registrate `MC1.21-1.3.0+67`.
- Sable Companion `1.6.0` — транзитивная API-зависимость Sable; этот аддон её не включает в свой JAR.
- Метаданные точного релиза Sable `2.0.6` подтверждают версии и Java. Gradle-сборка и запуск игры пока недоступны из-за ошибок загрузки дистрибутива Gradle. Подробности — в [UPSTREAM_RESEARCH.md](./UPSTREAM_RESEARCH.md).

## Состояние

### Реализовано

- Каркас Gradle-проекта для Java 21 / NeoForge, метаданные мода и конфигурации запуска клиента/сервера.
- Базовая интеграция Create/Sable уже есть в Sable 2.0.6 (физика, обработка столкновений, проекция луча взаимодействия); этот аддон не добавил игровой функциональности.

### Экспериментально

- Пока ничего.

### Запланировано

- Проследить точный жизненный цикл Create, найти конкретно отсутствующую функцию и безопасную точку расширения, не реализованную уже в Sable.
- Реализовать и проверить эту минимальную подтверждённую функцию, включая сохранение и разборку; не дублировать интеграцию Sable.
- Изучить nested contraptions/подшипники, поезда и интерфейсы предметов/жидкостей после анализа исходников и API.

### Не поддерживается

- Fabric и Forge.
- Интеграция Valkyrien Skies и поведение Create: Interactive, привязанное к Minecraft 1.20.1.
- Любые функции, не перечисленные в «Реализовано».

В каркасе пока нет игровой интеграции, блоков-маркеров, рецептов, предметов, изменений подшипников или поездов и передачи через интерфейсы.

## Установка

Релизного JAR пока нет. Не устанавливайте этот каркас разработки в игру. После появления проверенного релиза установите указанные версии NeoForge, Create и Sable 1.21.1 и на клиент, и на сервер, затем следуйте инструкциям к релизу.

## Сборка

Установите JDK Java 21 и запустите в корне репозитория:

```powershell
.\gradlew.bat build
```

Запуск окружений разработки:

```powershell
.\gradlew.bat runClient
.\gradlew.bat runServer
```
